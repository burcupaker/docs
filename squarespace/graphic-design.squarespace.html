If three of these sound familiar, the problem isn’t design talent. It’s that nothing connects one request to the next.

The deeper diagnosis

Design gets done one request at a time. So it never adds up to a brand.

Nobody chose to look inconsistent. Each piece was made quickly, by whoever was free.

  1. Year 1

The fix isn’t a rebrand. It’s one set of files and a way to ask for design.
